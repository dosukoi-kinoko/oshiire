# オシイレ アイデアバックログ

要件定義書 v1.2 の追加レビューで出た「もっと魅力的にするコンテンツ」案。
**まだ要件ではない**。オーナーが採用を決めたものだけ要件定義書へ昇格させる。

評価軸: 🔥バイラル力（口コミ・シェアされる力）/ 💰課金動機 / 🛠実装コスト（低=無料枠内で軽い）

## S級（強く推奨: バイラル装置になる）

### 1. 推し活年間まとめ「オシイレ Wrapped」 🔥🔥🔥 💰 🛠低〜中
Spotify Wrapped方式。毎年12月に「あなたの2026年推し活」を自動生成 —
参戦回数・書いた記録数・使った金額・一番会いに行った推し・獲得バッジ — を
数枚のスライド風カードにして布教カード形式でシェア。
- 推し活界隈はX/Instagramストーリーでの「今年のまとめ」文化が強く、**年1回の爆発的な認知獲得装置**になる
- 既存データの集計だけなので実装コストが低い（Canvas API流用）
- 「来年のまとめを充実させたい」→ 記録習慣の動機=リテンションにも効く
- プレミアム限定の特別デザイン版を用意すれば課金動機にも

### 2. 推し活ヒートマップ（草カレンダー） 🔥🔥 🛠低
GitHubの草のように、記録・参戦の頻度を1年分の色マスで可視化して推しページに表示。
「積み上がる実感」（企画書UXの核）を一目で表現でき、スクショがそのまま布教素材になる。
Wrapped(#1)の素材にも流用可能。

### 3. チケット当落記録 🔥🔥 🛠低
参戦記録の前段として「申込→当選/落選」を記録し、当選率を表示。
「当落」は推し活最大の感情イベントで、当選報告のシェア文化が既に存在する。
落選も「落選◯連からの当選」バッジで物語に変える。カレンダー(FR-16)・記録(FR-17)と自然に連携。

## A級（推奨: 世界観を深める）

### 4. 祭壇モード 🔥🔥 💰 🛠中 → ✅ **採用済み（要件定義書 FR-26a へ昇格 / v1.3, 2026-07-04 オーナー決定）**
グッズ写真を選んで「祭壇」風の1枚レイアウトを自動生成（誕生日祭壇文化に対応）。
グッズ管理(FR-20)のデータ流用+Canvas API。推し誕生日(FR-16a)と連動して
「そろそろ祭壇の準備をしませんか?」と提案。写真の権利は自分で撮ったグッズ写真なので布教カードより安全。

### 5. 遠征記録 🔥 🛠低〜中
参戦記録に「遠征」フラグ+訪問地リスト（テキスト。地図APIは使わずゼロコスト・位置情報なし方針を維持）。
「今年は5都市に遠征」がWrappedやヒートマップの素材になる。交通・宿泊費は予算トラッカー(FR-21)のカテゴリに追加。

### 6. 推しプロフィール帳テンプレート 🔥🔥 🛠低
「自己紹介カード/オタクプロフィール帳」文化に対応。推しデータ+自分の推し活スタイルを
かわいいテンプレに流し込んで画像出力（布教カードの亜種）。新規ユーザーが**登録直後に作れる
最初のシェア体験**になる（Wrappedは年末まで待つ必要があるが、これは初日から拡散に効く）。

## B級（検討: 差別化・満足度向上）

### 7. 積みグッズ消化チャレンジ 💰 🛠低
「積みグッズ」タグ(FR-20)のゲーム化。消化率メーター+「今週の1積み」提案+消化バッジ。
罪悪感を可愛く昇華する体験は他アプリにない。

### 8. 予算トラッカーの「幸せ換算」表示 🛠低
支出額をそのまま見せると罪悪感で機能がOFFにされがち。「今月は推しに¥12,000の愛を注ぎました」
「参戦1回あたり¥3,000の思い出」のようなポジティブ文言に切替可能にする（真面目な集計表示と切替式）。

### 9. 「推し始めた日」からの経過日数を常時表示 🛠低
推しカードに「推し歴 1,234日目」。FR-16aの節目通知と対で、毎日数字が増える=毎日開く理由になる。

## 見送り（検討済み・理由付き）

| アイデア | 見送り理由 |
|---|---|
| 推しからの疑似メッセージ/AIキャラ | 世界観を壊すリスク+生成AIコストがゼロコストに反する |
| 地図で遠征マップ表示 | 位置情報・地図APIコスト。テキスト遠征記録(#5)で代替 |
| フレンド機能・記録の相互閲覧 | フェーズ3コミュニティで再検討（安全設計が前提） |
| 金銭的な招待インセンティブ | GR-06の方針通り恒久見送り |
